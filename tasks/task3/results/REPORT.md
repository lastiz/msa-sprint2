# Отчёт

Подграф бронирований подключён к gRPC-сервису, реализованному в задании 2: вместо заглушки используется метод получения списка бронирований. Перед обращением к сервису проверяется идентификатор пользователя в заголовке запроса. Доступ разрешён только к собственным бронированиям.

Подграф отелей загружает сведения через REST API монолита и разрешает федеративные ссылки на отели по их идентификаторам. Apollo Gateway объединяет схемы обоих подграфов и передаёт пользовательский заголовок в подграф бронирований для проверки прав доступа.

Проверено три сценария:
- при запросе собственных бронирований возвращаются сведения о бронированиях и связанных отелях;
- попытка получить чужие бронирования отклоняется с кодом FORBIDDEN;
- запрос без заголовка идентификатора пользователя отклоняется с кодом UNAUTHENTICATED.
